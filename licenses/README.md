# Licenses in daemonarchy-ports

This repository is part of the Daemonarchy project (see [`../LICENSE.daemonarchy`](../LICENSE.daemonarchy); the repository map is in HACKING.md of https://github.com/jordanhubbard/daemonarchy). It is a fork of the FreeBSD Ports Collection. `COPYRIGHT` (FreeBSD's) is untouched; `LICENSE.daemonarchy` is Daemonarchy's statement, and this directory is the index.

Daemonarchy-original work carries the license terms only (BSD-2-Clause), with no copyright notice. Third-party and upstream-derived components keep the upstream notices, which are retained as their licenses require.

This list makes no claim that the licenses of transitive dependencies are represented. It lists the components of this repository and the licenses verified for them, with the evidence for each. Packages built from this tree and published in Daemonarchy's feed carry their own license metadata, which is not reproduced here unless it is listed below.

## What is under which terms

1. The tree as a compilation (Makefiles, `Mk/`, `Tools/`, patches and other files that FreeBSD maintains): the terms in FreeBSD's `COPYRIGHT` file in the root of this repository, copied verbatim to `licenses/FreeBSD-ports-COPYRIGHT.txt` (it reads "The compilation of software known as the FreeBSD Ports Collection is distributed under the following terms: Copyright (C) 1994-2026 The FreeBSD Project", followed by a two-clause BSD text). That text covers the compilation, not the software each port builds. Anything in the tree that is not listed in section 3 follows it.
2. The software each port builds has its own license, declared in the port's `LICENSE=` line. That is not reproduced per port here. A scan of the `Makefile` of every port directory in this tree (category/port; `Mk`, `Tools`, `Templates`, `docs`, `flavors`, `skills` excluded) found: ports with a Makefile: 35290; ports with no LICENSE= line: 5926 (ports that inherit it from a master port, or declare none; not examined further). The `LICENSE=` words that occur most, with the number of ports: MIT 7311, ART10 3540, GPLv1+ 3430, APACHE20 3284, GPLv2 3053, BSD3CLAUSE 2479, GPLv3 1939, BSD2CLAUSE 1737, GPLv2+ 1503, LGPL21 806, GPLv3+ 764, LGPL21+ 442, LGPL3 383, ISCL 317, OFL11 276, ART20 257, AGPLv3 252, MPL20 245, PD 218, RUBY 200, LGPL3+ 165, ZLIB 153, LGPL20 138, BSL 116, BSD4CLAUSE 110, CC0-1.0 95, LGPL20+ 93, EPL 87, PHP301 84, PSFL 70. This is a scan of declarations made in the Makefiles, not a verification against upstream sources.
3. Daemonarchy-specific content, below.

## Texts and their sources

- `BSD-2-Clause.txt`: the SPDX BSD-2-Clause text from spdx/license-list-data (commit 31846481de7ea17d92f2f46fad76abe58b2e9bb0, `text/BSD-2-Clause.txt`), with the template line `Copyright (c) <year> <owner>` removed on the operator's instruction. The rest is unchanged.
- `FreeBSD-ports-COPYRIGHT.txt`: byte for byte the root `COPYRIGHT` of this repository at the commit of this change.
- `upstream/*`: each file is the upstream project's own license file, fetched with the GitHub API at the ref stated in the row that cites it, unmodified. File names encode `category__port__path`. They carry the upstream copyright notices, which are retained as their licenses require.
