# Ports authority and acceptance map

<!-- literate-ai:authority-reviewed sha256:76fba7b69976b67c1eda513eadac2e7ac128491390be616eaddfc0d9137f605b -->

`PROJECT.md` owns the complete ports requirements. The
[unit guide](../user/ports-units.md) defines the initial real closure; the
[active queue](../roadmap/active-work.md) retains unfinished qualification.

| Requirement | Initial authored boundary | Remaining evidence |
| --- | --- | --- |
| PORT-G1 complete ownership | liblz4 origin and shared framework contracts | Complete origin/support catalog and exact native conditional dependencies |
| PORT-G2 common execution | Original make targets and retained interfaces | Installed LitAI source/ports target execution and measured executor comparison |
| PORT-G3 exact native inputs | Distfile/Mk/patch/options/bootstrap requirements | Complete custody, actual dependency bindings and correct invalidation |
| PORT-G4 per-unit packages | Original tests, independent acceptance and pkg contracts | Actual retained results, both BOMs/provenance and disposable-VM recovery |
| PORT-G5 upstream authority | In-place fork and separate integration branch | Reviewed original authority, regular native refresh and designated cut-over |

Original ports, Makefiles and upstream tests remain implementation authority.
The generation-workflow declaration is a candidate-review schema, not authority
to replace originals. A reviewed Standard binding selects installed framework
bytes; it cannot award native execution, package or release acceptance. Missing
current evidence must keep verification incomplete.
