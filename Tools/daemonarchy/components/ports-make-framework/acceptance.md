every input to this owner or an explicit separate owner. Reject unowned,
ambiguous, redirected, stale or unsupported inputs. Registration does not
establish complete ports framework coverage.

Demonstrate checksum/dependency refusal, unprivileged isolated staging and native
package metadata/payload preservation. Change an actually consumed shared input
and observe affected consumer invalidation, including its test/package state.

Verify the source/build pkg contains the selected original files, licenses,
both BOMs and actual bootstrap/dependency provenance. Preserve upstream import
and selection rollback without introducing wrappers throughout original port
directories. Metadata or a direct make probe cannot replace these results.
